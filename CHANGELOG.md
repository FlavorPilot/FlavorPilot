# Changelog

## 0.2.0

- Migrated from a Next.js full-stack layout to a Next.js + NestJS monorepo.
- Added Fastify, Drizzle/PostgreSQL, Supabase token validation and Docker deployment.
- Extracted shared contracts and deterministic Flavor Engine packages.
- Added authoritative dish CRUD, privacy rules, version snapshots and remix lineage.
- Removed server business logic from Next.js.
- Added strict catalog-reference validation, immutable remix ancestry and database defense-in-depth triggers.
- Added an npm-compatible workspace layout and dependency-free structural smoke test.
- Added container-platform `PORT` support and a dynamic API healthcheck.
- Made dish update contracts explicit so partial updates cannot inherit create-time defaults.

## 0.1.0

- Initial bilingual TasteCraft MVP.
